# МОЗАИКИ СКВОЗЬ ЭПОХИ — стартовый сайт

## Что внутри
- `index.html` — тексты, разделы, заглушки и структура сайта.
- `styles.css` — молочный дизайн, мозаичный заголовок, адаптация под телефон.
- `script.js` — боковое меню, переключение разделов и интерактивная карта.

## Как посмотреть сайт на компьютере
Самый простой способ — открыть `index.html` в браузере. Для полноценной проверки лучше использовать расширение Live Server в Visual Studio Code.

## Как добавить мозаику на карту
Открой `script.js`, найди `const mosaics = [ ... ]` и добавь объект по шаблону:

```js
{
  title: "Название или описание",
  coords: [49.806, 73.085],
  year: "Год создания",
  author: "Автор",
  subject: "Что изображено",
  image: "https://ссылка-на-фото.jpg",
  source: "Источник сведений и фотографии"
}
```

Координаты — сначала широта, затем долгота. Получи их для реального места в картографическом сервисе. Не используй примерные координаты как подтверждённое местонахождение мозаики. Для изображения нужна прямая ссылка на файл, доступная в интернете; либо размести изображение в репозитории и используй относительный путь, например `images/mosaic-01.jpg`.

## Как заменить тексты
В `index.html` найди заглушки:
- `Здесь появится основной текст исследования`
- `Здесь будет текст о мозаичном искусстве...`
Замени только текст внутри соответствующего блока, не удаляя HTML-теги вокруг него.

## Как опубликовать бесплатно через GitHub Pages
1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Нажми `New repository`.
3. Назови репозиторий `mozaiki-skvoz-epohi`.
4. Выбери `Public`, затем `Create repository`.
5. Нажми `Add file` → `Upload files`.
6. Загрузи `index.html`, `styles.css`, `script.js` (и папку `images`, если добавишь фотографии).
7. Нажми `Commit changes`.
8. Открой `Settings` репозитория → `Pages`.
9. В блоке `Build and deployment` выбери `Deploy from a branch`.
10. В `Branch` выбери `main`, папку `/ (root)`, затем `Save`.
11. Подожди завершения публикации. Ссылка появится в разделе `Pages`; обычно она выглядит так:
   `https://ТВОЙ-ЛОГИН.github.io/mozaiki-skvoz-epohi/`

После каждого `Commit changes` GitHub Pages обновит сайт. Не публикуй личные данные, закрытые интервью или фотографии без разрешения.

## Карта и стоимость
Карта сделана на Leaflet с картографическими данными OpenStreetMap. Для базовой версии не нужен Google Maps API-ключ. Соблюдай атрибуцию OpenStreetMap и условия использования тайлов; для большого трафика понадобится подходящий провайдер тайлов.

## Важно для исследовательской работы
Подпиши каждую фотографию: что изображено, автор/источник фотографии, дата доступа или создания — если известна. Год создания мозаики и автор указывай только при наличии проверяемого подтверждения. Если сведения не установлены, так и напиши.
