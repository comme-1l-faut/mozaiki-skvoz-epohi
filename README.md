# МОЗАИКИ СКВОЗЬ ЭПОХИ

Исследовательский проект в рамках задания «Культурный контекст. Настоящее рядом».

**Тема:** Советское художественное наследие Караганды и Москвы в культурной памяти постсоветского пространства.

**Главная идея:** Советские мозаики — не просто элемент архитектурного декора. Это ценные носители знаний своей эпохи, отражающие представления общества о науке, прогрессе, труде, будущем и человеке.

## Что внутри

- `index.html` — разделы исследования, тексты, галереи фотографий.
- `styles.css` — молочный дизайн, шрифты Playfair Display + Inter + Cormorant Garamond, адаптация под телефон.
- `script.js` — боковое меню и переключение разделов.
- `images/` — папка с фотографиями мозаик (создай её сама и положи туда фото).

## Структура сайта

1. **О проекте** — введение, главная идея, задачи.
2. **История мозаичного искусства** — от неолита до современности.
3. **Караганда** — текст исследования + галерея фотографий в конце раздела.
4. **Москва** — текст исследования + галерея фотографий в конце раздела.
5. **Сравнительный анализ** — общее и различное в двух городах.
6. **Методология и источники** — методы исследования, список литературы, информация об использовании ИИ.

## Как посмотреть сайт

Самый простой способ — открыть `index.html` в браузере. Для разработки удобно использовать расширение **Live Server** в Visual Studio Code.

## Как добавить фотографии

### Шаг 1. Создай папку `images`

В корне репозитория (рядом с `index.html`) создай папку с именем **`images`** (латинскими буквами, маленькими).

### Шаг 2. Назови файлы правильно

Сайт ждёт фотографии с такими именами:

**Караганда (обязательные):**
- `krg-owners.jpg` — «Хозяева земли»
- `krg-geology.jpg` — «Геология»
- `krg-cosmonaut.jpg` — «Космонавт»
- `krg-mir.jpg` — «Мир»

**Караганда (дополнительные, если есть):**
- `krg-extra-01.jpg`
- `krg-extra-02.jpg`
- `krg-extra-03.jpg`

**Москва (обязательные):**
- `mow-mayakovskaya.jpg` — «Маяковская»
- `mow-komsomolskaya.jpg` — «Комсомольская»
- `mow-novoslobodskaya.jpg` — «Новослободская»
- `mow-pirogov.jpg` — «Исцеление человека»

**Москва (дополнительные, если есть):**
- `mow-extra-01.jpg`
- `mow-extra-02.jpg`
- `mow-extra-03.jpg`

### Шаг 3. Положи фото в папку `images`

Просто перетащи фотографии в папку. Формат — `.jpg`, `.jpeg` или `.png`.

> ⚠️ Если у тебя `.heic` (с айфона) — сначала конвертируй в `.jpg` через любой онлайн-конвертер.

### Шаг 4. Подпиши фото

По ТЗ **каждая фотография должна иметь подпись**: что изображено, автор/источник, дата. Подписи уже вписаны в `index.html` в блоках `<figcaption>`. Можешь отредактировать их под себя.

### Шаг 5. Если мозаик больше, чем слотов

В `index.html` найди комментарий `<!-- ДОПОЛНИТЕЛЬНАЯ МОЗАИКА -->` и скопируй блок `<figure>...</figure>` рядом, поменяв имя файла и подпись.

## Как заменить файлы на GitHub

### Через браузер (самый простой способ)

1. Зайди на свой репозиторий: `github.com/ТВОЙ-ЛОГИН/mozaiki-skvoz-epohi`.
2. **Заменить `index.html`:**
   - Кликни на файл → справа сверху нажми **карандаш** ✏️ (Edit this file).
   - Выдели всё: **Ctrl+A** (на Mac — **Cmd+A**).
   - Удали.
   - Вставь новый код.
   - Внизу нажми **Commit changes…** → **Commit changes**.
3. **Повтори для `styles.css` и `script.js`.**
4. **Добавить фото:**
   - На главной странице репозитория нажми **Add file → Upload files**.
   - Перетащи туда все фото из папки `images`.
   - **Commit changes**.

GitHub Pages автоматически обновит сайт через 1–3 минуты.

### Через Visual Studio Code

1. Открой папку проекта.
2. Замени содержимое `index.html`, `styles.css`, `script.js`.
3. В папку `images` положи все фото.
4. Слева во вкладке **Source Control** нажми **+** у каждого файла.
5. Напиши сообщение (например, «обновил контент и добавил фото») → **Commit** → **Sync changes**.

## Как опубликовать через GitHub Pages (если ещё не опубликовано)

1. Создай аккаунт на https://github.com/.
2. Нажми **New repository** → назови `mozaiki-skvoz-epohi` → **Public** → **Create**.
3. **Add file → Upload files** → загрузи `index.html`, `styles.css`, `script.js` и папку `images`.
4. **Commit changes**.
5. **Settings → Pages → Build and deployment → Deploy from a branch** → выбери `main`, папку `/ (root)` → **Save**.
6. Ссылка появится в разделе Pages: `https://ТВОЙ-ЛОГИН.github.io/mozaiki-skvoz-epohi/`.

## Важно

- **Имена файлов должны точно совпадать** с тем, что написано в `src="images/..."`. Регистр важен: `KRG-EXTRA.jpg` и `krg-extra.jpg` — это разные файлы.
- **Не публикуй личные данные**, закрытые интервью или фотографии без разрешения.
- **Все фотографии должны иметь подписи** с указанием источника.
- **Не выдумывай авторов и годы** — если не знаешь, так и напиши «автор не установлен» или просто не указывай.

## Использование ИИ

ИИ применялся только для определения объектов исследования, валидных для задания «Культурный контекст». Все факты, даты, имена и сведения проверялись лично по научным публикациям, архивным материалам и в ходе полевых наблюдений. ИИ **не использовался** для:
- придумывания фактов о мозаиках;
- создания «архивных» изображений;
- подмены работы с источниками.
